# MAYA Core Rule

Treat `AGENTS.md` as authoritative project behavior and `docs/PRODUCT_SPEC.md` + `docs/ARCHITECTURE.md` as authoritative product/architecture context.

Always inspect existing code before adding files.

Never use a giant prompt as the architecture. Intelligence must be decomposed into explicit modules with typed interfaces.

Never claim simulated affect or behavior is literal human emotion/consciousness.

Every meaningful code change requires tests and, when relevant, documentation/ADR updates.
